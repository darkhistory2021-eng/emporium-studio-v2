THE EMPORIUM STUDIO 2.0

Mobile-first episode and scene planner.

Features: paste a script and split it into editable scene cards; edit dialogue, visual direction, character action, camera and duration; upload the Keeper reference image; preserve character continuity instructions in exported scene prompts; export a scene prompt pack or JSON project backup.

Important: this version does not generate AI video, voices or lip-sync. It prepares a structured production plan. A real AI video model requires an external service or suitable remote GPU, plus a secure backend for API credentials. Never put private API keys into this static website.

To publish: replace index.html in your existing GitHub repository with this version. Keep manifest.webmanifest and sw.js. GitHub Pages will redeploy automatically.
